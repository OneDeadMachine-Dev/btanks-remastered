Проверено 20 октября 2026 года. Здесь разделены авторы оригинала, происхождение локального кода и современный порт.

Сверка с внешними источниками:

- [Официальный проект на SourceForge](https://sourceforge.net/projects/btanks/) — Battle Tanks, аккаунт сопровождающего `megath`.
- [Официальные новости SourceForge](https://sourceforge.net/p/btanks/news/) — сообщение от 27 ноября 2013 года о переносе Battle Tanks в `github.com/whoozle/btanks`, а Clunk в `github.com/whoozle/clunk`.
- [Репозиторий автора на GitHub](https://github.com/whoozle/btanks) — исходный проект; содержит знакомые `engine`, `objects`, `sdlx`, `mrt`, `editor`, данные и CMake-сборку.
- [Clunk на GitHub](https://github.com/whoozle/clunk) — отдельная библиотека позиционного/бинаурального звука того же автора. Современная ветка не равна встроенной в этот checkout версии.
- [Историческая страница руководства в исходном пакете Debian](https://sources.debian.org/src/btanks/0.9.8083-8/debian/html/index.html/) — сохранённая документация с ранними титрами и описанием игры. Использована как дополнительная историческая сверка.

Старый сайт `https://btanks.sourceforge.net/` при прямом обращении инструментом чтения не открылся. Это ограничение проверки, а не доказательство окончательной недоступности сайта. Авторство удалось установить по локальным титрам и другим источникам.

## Какая версия лежит здесь

В `btanks-code/trunk/.svnversion` указано **8098**. Сохранившаяся локальная SVN-база `btanks-code/.svn/wc.db`, открытая только для чтения, указывает:

- Repository root: `https://svn.code.sf.net/p/btanks/code`.
- Корень рабочей копии и `trunk`: revision **8098**.
- Last changed author: **megath**.
- Last changed date: **2010-07-15 12:32:00 UTC**.

Отдельная база `btanks-code/trunk/clunk/.svn/wc.db` указывает `https://svn.code.sf.net/p/clunk/code`, revision **125**, автора `megath`, дату **2010-09-25 08:43:33 UTC**.

Эти даты — метаданные сохранённых SVN-копий. Они не означают, что все файлы написаны в 2010 году, и не подтверждают неизменность кода после импорта. Заголовки copyright 2006–2009 описывают другой аспект истории. Поэтому формулировка «игра 2006–2009 годов» полезна для периода исходной команды, но не для даты всех исходников данного checkout.

На SourceForge опубликован архив [btanks 0.9.8083 от 30 декабря 2009 года](https://sourceforge.net/projects/btanks/files/btanks-source/). Локальный r8098 — другая ревизия; это не побайтовая копия указанного релизного архива.

На момент обращения к GitHub API вершина `whoozle/btanks` — [`21b74daaf745532533ef2f218b388fa4f3533e01`](https://github.com/whoozle/btanks/commit/21b74daaf745532533ef2f218b388fa4f3533e01), 23 сентября 2022 года, merge PR #5. Это датированный снимок состояния внешнего источника, а не обещание его неизменности. Полное сравнение этого upstream с локальным ремастером не выполнялось.

## Локальный ремастер

Локальная Git-история начинается **5 октября 2026 года** коммитом `79acc89`: baseline r8098 + Clunk r125 и рабочий порт macOS через SDL 1.2 compatibility layer. Далее идут перенос на SDL3, GPU-рендер, исправления клиппинга и координат мыши, широкий экран, атласы, фиксированный шаг симуляции, переносимая упаковка `.app`, WebAssembly, управление, сохранение и отключение старого master server по умолчанию.

В текущей истории **21 коммит**, все записаны под именем **OneDeadMachine**. Последний изученный — `ffc98c5` от 6 октября 2026 года. Это подтверждает авторство записей в локальной Git-истории; история не позволяет установить, какими инструментами создавалось каждое изменение.

`git remote -v` не выводит настроенных remote. Поэтому публикация ремастера на GitHub или связь этого checkout с конкретным публичным форком **не установлена**. Официальный GitHub оригинала найден через сообщение самого проекта, а не через remote локальной папки.

## Лицензионные сведения из файлов

Это указатель на тексты в репозитории; отдельный правовой анализ не выполнялся.

- [Основной `LICENSE`](../btanks-code/trunk/LICENSE) содержит GNU GPL v2. Заголовки игровых исходников указывают GPL версии 2 **или более поздней**.
- [LICENSE.EXCEPTION](../btanks-code/trunk/LICENSE.EXCEPTION) называет Netive Company Ltd., Новосибирск, и описывает специальные условия сочетания с дополнительным закрытым контентом и отдельные письменные соглашения. Это не универсальное разрешение произвольному форку закрыть исходники.
- Встроенный [Clunk LICENSE](../btanks-code/trunk/clunk/LICENSE) — LGPL 2.1; заголовки ряда файлов `mrt` и `sdlx` также используют LGPL. Нельзя переносить обозначение MIT с современного GitHub Clunk на эту старую локальную копию.
- Встроенный Lua 5.1.5 имеет собственное разрешительное уведомление, stb_image — собственные варианты лицензии в заголовке. При поставке нужно исходить из конкретных встроенных файлов, а не общего названия зависимости.

Для технического продолжения важно сохранять исходные титры, copyright и тексты лицензий. Конкретную модель распространения и комплект уведомлений следует определять по итоговому составу выпуска.
