# Screenshots

The PNG files are unedited screenshots of the current Battle Tanks Remastered Web build, captured during local validation on 21 October 2026. The JPEG social preview is the original splash artwork, copied unchanged from the game assets.

- `battle-tanks-cover.png` — main menu and original splash artwork.
- `curfew.png` — Team Deathmatch gameplay after selecting a team.
- `baykonur.png` — cooperative map.
- `platform.png` — cooperative map with the space setting.
- `social-preview.jpg` — original `splash_1280_1.jpg` artwork, used for GitHub social previews (below the 1 MB upload limit).

Original game artwork is credited to the original Battle Tanks team in [CREDITS.md](../../CREDITS.md). These images do not introduce a separate license or imply new artwork by the remaster maintainer. The browser FPS indicator is part of the capture; it is not a benchmark claim.
