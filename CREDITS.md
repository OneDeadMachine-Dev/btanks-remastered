# Credits & provenance

Battle Tanks Remastered builds on the original **Battle Tanks** by **Netive Media Group**. The modern port does not replace the original team's authorship.

Earlier documentation also credits Vladimir Zhuravlev as “Private Face”. This checkout uses “VZ”. Copyright ownership and additional notices remain as recorded in the individual files and original license texts.

## Modern port

**[OneDeadMachine](https://github.com/OneDeadMachine-Dev)** — macOS and Web port, platform modernization, packaging, maintenance and repair work for this remaster.

The personal motivation is simple: Battle Tanks was a game the maintainer loved playing with his sister as a child. This project is a way to return to it and keep it playable on current systems.

The screenshots in [docs/images](docs/images/) show the current Web build using the original game artwork. They are not a new asset pack. The original artist credit remains with the original team.

## Source lineage

- Battle Tanks: [SVN source repository](https://svn.code.sf.net/p/btanks/code), revision **8098**, last-changed date recorded in the imported working copy: **15 July 2010**.
- Bundled Clunk: historical revision **125**, recorded date **25 September 2010**.
- Modern remaster: local development history begins in October 2026 and retains the imported source and original notices.

The 2010 date identifies the imported source snapshot. It is not the end date of the original project's maintenance. On **27 November 2013**, the [official SourceForge announcement](https://sourceforge.net/p/btanks/news/) directed development and support to [whoozle/btanks](https://github.com/whoozle/btanks), with Clunk moving to [whoozle/clunk](https://github.com/whoozle/clunk).

This checkout contains an older bundled Clunk revision. Its license must be read from [the bundled LICENSE](btanks-code/trunk/clunk/LICENSE), rather than inferred from the current upstream repository.

See the [dated historical investigation](docs/HISTORY_AND_AUTHORS.md) for the evidence behind this provenance summary, and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for bundled dependencies.
